# Data Sources Policy

## Current Status: Demo Data Only

All data currently served by the portal is **demo/synthetic data** generated by the seed script.
It does not represent actual PSX market prices.

Every demo record has `is_demo = true` in the database.
The UI displays: "Demo Data — Not Live Market Data"

## Authorised Data Import

To import real data, an authorised party must:

1. Obtain a licence from the Pakistan Stock Exchange (PSX) or an authorised data vendor
2. Use the Data Import Centre at `/data-portal/admin/import`
3. Upload CSV/XLSX files in the documented format
4. Real records have `is_demo = false` and `data_source = 'csv_upload'` or `'api_feed'`

## Data Source Types

| Code | Description |
|------|-------------|
| `demo_data` | Synthetic demo data — not real market data |
| `manual_import` | Imported via CSV/XLSX upload |
| `csv_upload` | CSV file uploaded through import centre |
| `excel_upload` | XLSX file uploaded |
| `api_feed` | Automated feed from licensed data provider |
| `manual_entry` | Entered manually through admin forms |

## No Unauthorised Scraping

The portal does not scrape PSX or any third-party website.
Scraping PSX data without authorisation violates their terms of service.

## Data Licence Notes

Each record includes a `data_source` field.
The `import_batches` table logs the origin of every import.
The `audit_logs` table tracks who imported what and when.
